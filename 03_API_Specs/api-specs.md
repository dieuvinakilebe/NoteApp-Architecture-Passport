# Спецификация API NoteApp

## 1. Аутентификация
- `POST /api/v1/auth/login` — Вход в систему, получение JWT токена.

## 2. Управление заметками (CRUD)
- `GET /api/v1/notes` — Получить список заметок (с параметром `?updated_since=timestamp` для синхронизации).
- `POST /api/v1/notes` — Создать заметку.
- `PUT /api/v1/notes/{id}` — Обновить заметку (требует передачи `version` для контроля конфликтов).
- `DELETE /api/v1/notes/{id}` — Удалить заметку (мягкое удаление / soft delete).

## 3. Синхронизация
- `POST /api/v1/sync/batch` — Пакетная отправка локальных изменений с клиента. Возвращает статус применения операций и новые данные с сервера.
