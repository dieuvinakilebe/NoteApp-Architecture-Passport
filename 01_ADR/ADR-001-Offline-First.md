# ADR 001: Выбор архитектуры Offline-First и микросервисов для NoteApp

**Статус:** Принято
**Дата:** 20.10.2026

## Контекст
Аудит существующих решений (Практическое задание 1) выявил, что главные жалобы пользователей связаны с потерей данных и зависаниями при синхронизации. Пользователи ожидают мгновенного доступа к заметкам без интернета и гарантии сохранности данных.

## Решение
1. **Клиентская часть:** Использовать архитектуру **Offline-First**. Локальная база данных (SQLite) является основным источником истины для интерфейса. Изменения сначала сохраняются локально, затем ставятся в очередь на синхронизацию.
2. **Серверная часть:** Использовать **микросервисную архитектуру** (выделенные сервисы для аутентификации, заметок и синхронизации).

## Последствия
- **(+)** Приложение работает без интернета. Нет потери данных при обрыве связи.
- **(+)** Изоляция сервиса синхронизации позволяет масштабировать его независимо от других.
- **(-)** Усложняется клиентская логика (разрешение конфликтов версий при синхронизации).
