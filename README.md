# Архитектурный паспорт: Приложение для заметок (NoteApp)

**Дисциплина:** Создание клиент-серверных приложений
**Студентка:** Дыевина Килебе (Группа К3421)

## Обоснование выбора проекта 
В рамках Практического задания 1 был проведен аудит приложений для заметок (на примере Evernote). Анализ показал, что основные проблемы пользователей связаны с синхронизацией, стабильностью и целостностью данных. 
В качестве собственной вариации для архитектурного паспорта выбрано проектирование нового клиент-серверного приложения для заметок. Архитектура спроектирована с учетом ошибок конкурентов (подход Offline-First, надежная очередь синхронизации, изоляция модулей).
